# Close the #102, #126 and #122 leftovers Implementation Plan (#145)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the three QC passes' unfiled findings are closed: `doctor.sh` and `/codeo:issue` agree on what turns `issue.priority` on and an issue never carries two `priority:` labels, `claim.sh` gives one remedy that never says to retitle for a branch `init` cut, and the pages and comments that describe `inflight.sh`'s `waits:` line say what it prints, with `bash tests/run.sh` passing.

One new test (`touched_of`) with a fake `git`. Order: scripts and their cases first (Tasks 1, 3), then the skill and doc wording (Tasks 2, 4, 5), then the one new test (Task 6), then the CHANGELOG (Task 7), last because it is the file most likely to collide with #143 and #144.

**Tech Stack:** bash, git, awk, jq; the `shell` suite (`bash tests/run.sh`, or one file with `bash tests/<name>.test.sh`).

**Spec:** `.codeo/145/init.md` `## Outcome` (the issue's acceptance criteria) and `.codeo/145/plan.md` Q1-Q5, whose answers are the design. Reference doc: none; nothing here is a standing decision.

## Global Constraints

- **Q1: the pages change, `inflight.sh` does not.** It still prints `review — dossier archived` for every dossier under `.codeo/done/<N>/` whose archive is not on the base branch yet, with no pull-request lookup (its human blocks stay git-only). The pages say that, and triage's *resume* names the pull request to review when one is open and `/codeo:close` in that issue's checkout when there is none or it was closed unmerged, from the state triage already reads.
- **Q2: stated, not changed.** *Resume* on an `unassigned:<N>` item names the step and stops nothing; the item returns each run until the workflow has an assignee, and *dismiss* stops it. Triage's ledger rules do not change.
- **Q3: a fake-`git` case for `touched_of`.** The nine existing `touched_*` cases stay; one is added for the branch they cannot reach (an unparsable tip date). `scripts/inflight.sh` does not change for it.
- **Q4: an outside-the-four priority is asked about again**, naming the four, in step 6 of `skills/issue/SKILL.md`.
- **Q5: sequence after #144.** The footprint's `sequenced:` line names #144; `/codeo:implement` starts once #144 has merged, and Task 7 runs `bash scripts/sync-main.sh` first and keeps both sides on a CHANGELOG conflict (a likely collision with #143 and #144 too).
- **`"true"` is off in both places.** `doctor.sh` already tests a bool and does not change for it; the skill changes to read `.issue.priority == true` (the #102 plan's constraint, which the QC held the skill to).
- **claim.sh messages that stay.** The three "retitle #N only for an issue reopened after its merge" clauses are about a reopened issue, not a branch `init` cut; `tests/claim.test.sh` and `skills/init/SKILL.md` pin them.
- **No behaviour change to the pipeline.** No gate, lock, branch name or exit code changes; only what two messages say, what the printed `doctor.sh` command quotes, and what the pages and comments claim.
- **Documentation moves** (one task each): `skills/issue/SKILL.md` and `docs/skills.md` (Task 2), `scripts/claim.sh`'s header (Task 3), `scripts/inflight.sh` comments and `docs/handoff.md` (Task 4), `skills/triage/SKILL.md` and `docs/skills.md` (Task 5), `CHANGELOG.md` (Task 7). No wiki module. A page that describes behaviour says what the system does and names no issue; the CHANGELOG is where issue numbers go.
- **No environment, no lease, no host tasks.** No shared environment, wiki module, invariants document or exclusive resource is configured and the lock's host is `container`, so every task runs in this checkout and every proof is `bash tests/run.sh <pattern>` or one test file.
- **A mutation is a proof.** Where a task says "mutate", the implementer reverts the change with `git checkout -- <file>` straight after; no mutation is committed.
- **Out of scope**, as the issue says: #126 F4 and F5, #102 F3 and F4, #131's leftovers.
- **Invariants:** none configured.
